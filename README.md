One status update of at most 120 characters, in the voice of a lost sock that has ended up somewhere it should not be.

Bounty: [Funniest Lost Sock Status Update](https://make.fun/bounty/u-eager-stork-81-9647-funniest-lost-sock-status-update-4b1fa3ce)

## Entry

> Update: I escaped the laundry and live in the freezer. Cold, alone, and the peas keep asking where my other half went.

**118 characters** (limit: 120)

## How it runs

`main.ts` prints the entry and writes it to `/output/entry.txt` (or `$MAKEFUN_OUTPUT_DIR/entry.txt`):

```sh
node main.ts
```
